# Themes Base
    
## Install Themes 

Install base
```sh
git init $HOME && git remote add origin https://github.com/linuxthemes/base
```

Download themes
```sh
git pull
```

## Themes

Switch themes 
```sh
git checkout tokoyo-night
```

Make your own theme
```sh
git -b checkout the-best-theme 
```
