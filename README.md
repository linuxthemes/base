# linux themes base
![base](Pictures/image.png)


## install
```sh
git init -b main $HOME && git remote add origin https://github.com/linuxthemes/base
```
```sh
git pull && git submodule update --init --recursive
```

## themes

Switch themes 
```sh
git checkout tokoyo-night
```

Make your own theme!
```sh
git -b checkout the-best-theme 
```
```sh
git push 
```
