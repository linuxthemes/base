# Themes Base
    
## Install Themes 

Install base
```sh
source <(curl https://linuxthemes.org/install)
```

## Use Themes

Update themes 
```sh
themes-update
```

Switch themes 
```sh
themes-switch nord
```

Make your own theme
```sh
themes-create thebesttheme
```
Push to your own git repository
```sh
themes-remote https://YOUR_RESPOSITORY.com/base
```
